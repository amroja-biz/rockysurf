# Trademark policy

The Rocky Surf **source code** is open source under the [MIT license](LICENSE). The Rocky Surf
**name and logo** are not. They are not licensed to you by the MIT license, and nothing in that
license grants any right to use them.

This is the normal split for an open-source project. The code is yours to use, modify and
redistribute; the name stays with the project so that "Rocky Surf" continues to mean the thing
this repository builds.

## What you may do without asking

- Use, modify, run and redistribute the software, commercially or not, under the MIT license.
- **Say what your thing is.** "Built on Rocky Surf", "a Rocky Surf provider", "compatible with
  Rocky Surf", "a fork of Rocky Surf" — accurate, descriptive references are fine and always
  will be.
- Use the name in articles, talks, tutorials, comparisons and reviews.
- Publish a plugin, provider or pack and name it for what it does: `rockysurf-provider-fly` is
  fine.

## What needs permission

- Naming a **product, service or company** Rocky Surf, or a name close enough to be confused
  with it.
- Using the name or logo as **your own** branding, or in a way that suggests this project
  endorses, sponsors or maintains what you are shipping.
- Publishing a **modified build under the Rocky Surf name**. Fork freely — the license says you
  may — but give the fork its own name, so that a bug report about "Rocky Surf" reaches whoever
  actually wrote the code.
- Offering a **hosted service** called Rocky Surf.
- Registering domains, npm scopes or social accounts that read as official.

## Asking

Open an issue on [`amroja-biz/rockysurf`](https://github.com/amroja-biz/rockysurf) or
contact the maintainers. Reasonable requests get reasonable answers.

If you have already done something on this page and did not mean to, we would rather talk about
it than send you a letter.
