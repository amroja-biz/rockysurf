## Decisions and rules

- **Everyone who runs an installation is its admin.** `isAdmin` is not a product distinction.
  Never add a "non-admin" route or describe a behaviour as "for admins". Memory file + brief.
- **CI shape** (#180/#182/#203): UI/docs-only PR → typecheck, tests, secret scan only; anything
  else → everything; pack-only PR → changed packs + dependents; push to main → everything,
  always. `main` has no branch protection — a skipped job that became "required" would block
  merges forever; the workflow comments say to remove the gates if protection is ever added.
- **A PR opened against a feature branch is a trap.** #193 was merged into `feat/user-script-184`
  after #187 had merged, and never reached main until re-landed as #196. Rule for the
  orchestrator: agents open PRs against `main` only; sequence by waiting, not by base-branch.
  And: an agent that is still extending a PR when the owner merges it (#207 → #210) must
  cherry-pick to a fresh branch.
- **Pack inputs are the pack author's namespace; Environment is the user's.** Same name in both
  is a 400. Reserved: what Rocky Surf exports, plus `ROCKYSURF_`, `GIT_CONFIG_KEY_`,
  `GIT_CONFIG_VALUE_`, `GIT_TERMINAL_PROMPT`, `GIT_CONFIG_COUNT` — and nothing else with `GIT_`.
- **`secrets.env` values are single-quoted** (#196). A form value is not a shape core controls;
  unquoted `FOO=a b` would run `b`, as root.
- **The startup script is plain text everywhere** (row, plan snapshot, `plan.json`). Keys go in
  Environment or a pack input, never in the script; the form says so.
- **A failed apt fetch costs a second, not a box** — two attempts per step in `agent.sh`, then
  ADR-0010 terminates. Bounded worst case 62 min per tool step (ADR-0015 clause 4).
- **Font**: Rocky Surf webfont on `h1`–`h4` only; body, fields, buttons, mono on the system
  stacks. `App.css` owns this (base design), `etched.css` never edits it for skin reasons.
- **Header wash**: base band opacity 0.62, etched 0.5; the header must stay opaque; no
  `backdrop-filter`; the mark stays one raster with a dark ground (designer's README).
- **Vendored design system stays verbatim**; a partial export is diffed file-by-file and only
  differing files copied; never copy an older export's file over a newer vendored one (the
  font export's `etched.css` predated the button work and was correctly skipped).
- **Everything a bootstrap step starts dies with the bootstrap** — the transient systemd unit
  reaps its cgroup. A pack that wants a daemon uses lingering + a user service
  (`desktops-and-daemons.md`), or leaves it to the guide (the Headlong pack does).
- **Agent teams**: the brief lives in the session scratchpad (`AGENT-BRIEF.md`) and carries the
  node-24 wrapper, the "owner's live app is off limits" rule (a Claude-in-Chrome tab is a
  separate, signed-out instance and lands in the owner's face — this bit once today), the CI
  shape, the admin ruling, and "landed today". Fable for diagnosis (#205 found the real cause in
  the owner's DB), Opus for cross-cutting, Sonnet for contained UI. Take CI watches centrally;
  an agent that stops "waiting on CI" needs "don't end your turn while X runs".

## Traps

- **The session's `grep` is a shell function that mishandles `-qv`.** Testing a workflow's
  `grep -qvE` locally gave wrong answers until run with `/usr/bin/grep`. ubuntu-latest has GNU
  grep; the workflows are right. Use `/usr/bin/grep` for anything that must match CI.
- **`gh run list --workflow X --limit N` is not sorted by time reliably**; filter by
  `headSha` via `gh api …/actions/runs?head_sha=` when a run for a specific commit matters.
- **The dcg guard blocks any command text containing `rm -rf`** — including a heredoc that
  merely writes a script containing it. The Headlong pack's clone retry clones into `mktemp -d`
  and `mv`s for exactly that reason. Use the Write tool for files that must contain the string.
- **`git cherry-pick -q` is not a flag.** Cost one turn.
- **A merged PR's branch keeps accepting pushes** — nothing tells the agent. Check
  `gh pr view N --json state` before extending anything.
- **The apt-mirror 404 is arm64 `ports.ubuntu.com` serving a stale index**, same package
  (`perl-base 5.38.2-3.2ubuntu0.4`) each time; `apt-get update` re-fetches the same bad index.
  #191 handles it; if it recurs on main, rerun.
- **`proxy.golang.org` drops HTTP/2 streams from GitHub runners** — only gas-town pulled from
  it; now nothing does.
- **QEMU amd64 on this Mac**: `uv` (Rust, from PyPI) segfaults on invocation; Bun does too. A
  pack that installs either has a CI-only amd64 leg; a personal pack has none. Prove the other
  steps standalone in the kept container (`--keep`, `docker exec … su -s /bin/bash rocky -c`).
- **`pipx install uv` puts `uv` and `uvx` in `~/.local/bin`**; upstream's Headlong installer
  writes its own PATH line to `.bashrc` only inside a container (`/.dockerenv`) — write the
  identical expanded line yourself, `grep -qxF`-guarded, so the harness sees one copy.
- **`category` on a pack tool is an enum: `agent` | `base`.** `utility`/`runtime` fail
  validation with an unhelpful test cascade; the message is in the `packs.test.ts` output.
- **Pack smoke containers are named per run** (`rockysurf-pack-smoke-<pack>-<arch>-<suffix>`),
  so arm64 and amd64 can run concurrently; `--keep` leaves them — `docker rm -f` afterwards.
- **A background Bash command is capped at 600 s**; an emulated smoke run exceeds it. Launch
  with `nohup … & disown` writing an exit file, and poll the file.
- **Vitest under node 20 says `webidl.util.markAsUncloneable is not a function`** — that is
  node, not a dependency; use the node-24 wrapper (`scratchpad/n24.sh`).
- Carried: `gh pr checks --watch` exits 0 on failure; `mergeStateStatus` is UNKNOWN ~10 s after
  any merge; `bundle-assets.test.ts` needs a web build first; `getByText` matches own text nodes.
