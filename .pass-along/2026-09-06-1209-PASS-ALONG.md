## Traps

- **The auto-mode classifier blocked `SendMessage` to a running agent** (the message carried a
  URL and a sha256). Agents that poll are fine; do not rely on mid-flight messages.
- **raw.githubusercontent.com caches `providers.json` for minutes** after a merge; read the
  merged file through `gh api repos/.../contents/providers.json` when checking a fresh merge.
- **`gh pr merge --delete-branch` on the shop deletes the branch a polling agent may be
  reading** — the #376 agent had the PR branch as its fallback source. Merge, then tell agents, or
  point them at the API.
- **A heredoc python step is not part of an `&&` chain** — `cmd && python3 - <<'EOF' … EOF` then
  a new line `git add …` runs the git line regardless of python's exit. PR #423 went up missing
  its index change and needed a second commit. Put the whole thing in one script.
- **`.git/index.lock` collisions** happen when an agent worktree runs git in the same repo;
  wait and retry, do not delete the lock.
- **`rockysurf token --help` still mints a token.** Unchanged.
- **Duplicate task-notifications**: an agent can notify twice for one completion.
