## Traps

- **`ROCKYSURF_ADMIN_PASSWORD` set = no banner, no message.** Commenting the export out of
  `.zshrc` does not remove it from an open terminal. Diagnose with
  `verifyPassword(<suspected value>, <stored hash>)` from `@rockysurf/core/dist/auth/passwords.js`
  against `settings.auth.local.passwordHash` in `rockysurf.db` — conclusive in one command.
- **Say it with proof the first time.** The owner rejected the correct diagnosis when it was
  delivered as inference; the hash check ended the argument.
- **Do not tag a release the owner has not reviewed**, even with the approval gate downstream.
- **npm read-path lag after publish** is per package and reached ~10 min for one of nine today;
  `npx` fails with `ETARGET … provider-aws@0.1.1` meanwhile. The release smoke step waits 15 min.
- **`gh pr checks --watch` immediately after a push says "no checks reported"** — runs are queued a
  few seconds later. Use `gh run list --branch` / `gh run watch <id>`.
- **macOS has no `timeout`**; use `perl -e 'alarm N; exec @ARGV' cmd…`. The child node process can
  outlive the alarm — check `core.lock` in the data dir and kill the pid.
- **The CLI has no `--data-dir` flag**; isolate a run with a config file setting `server.dataDir`
  and `server.port`.
- **`dcg` blocks `rm -rf` in Bash** for agents; use unique new directories instead.
- **Flakes**: #453 apt-retry (load), #459 SDK `dist/errors.js` race — both again today.
