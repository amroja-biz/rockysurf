## Traps

- **`AADSTS700213` on Azure OIDC = GitHub's immutable-id subject** — check the federated
  credentials before anything else; the log's "subject claim" line shows exactly what Entra saw.
- **`InvalidDeploymentLocation` = the deployment NAME is region-pinned**, not the resources.
- **eastus3 appears in SKU listings but the usages API rejects it** — not usable for quota.
- **Four instant polls are one poll**: foreground `sleep` is blocked, so a retry loop without
  a background task samples the same moment four times. Put delays in `run_in_background`.
- **`mergeStateStatus` can sit UNKNOWN indefinitely while the owner is mid-merge** (#267) —
  if checks are green, report green; don't chase the flag.
- **`git commit` commits the whole index** — a file someone else staged rides along (this bit
  `fecfd08`). Check `git status` before committing, or commit with explicit paths.
- **The dcg command guard scans heredoc CONTENT, not just commands** — prose containing
  git-ish trigger words inside a `cat <<EOF` block gets the whole command refused. Write such
  files with the Write tool instead.
- **`gh pr checks --watch | tail` duplicates rows** in its final output; count non-pass rows,
  don't eyeball.
- **zsh eats `echo ===`** (`=cmd` expansion) — quote separators in chained commands.
- Carried and still true: node 24 via `~/.nvm/versions/node/v24.19.0/bin`; `/usr/bin/grep`
  for CI parity; the harness screenshot/Playwright path needs
