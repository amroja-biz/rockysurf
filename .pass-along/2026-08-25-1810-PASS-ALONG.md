## Decisions and rules

- **No bundled price fallback, ever** (owner, ADR-0009): unreachable feed ⇒ honest
  "unavailable", never a stale number. Applies to any future provider on the feed.
- **Feed schema is a contract**: `schemaVersion: 1`, breaking change = new `/v2/` path.
  Readers reject a WHOLE document on any invalid price (spend cap consumes these numbers —
  degrade to unpriced, never to wrong).
- **fetchedAt must be when the numbers were READ, not when published**: GCP's doc carries its
  transcription date (2026-08-13 today) even though the workflow republishes daily. A future
  session "fixing" that stamp to now would be laundering staleness.
- **Azure catalogue is the union** of sizes priced in any covered region (PR #110's measured
  rationale, enforced by tests on `azureCatalogue()`); per-region honesty is downstream.
- **Catalogues (shapes/sizes/zones) stay bundled; only prices ride the feed** — without
  shapes there are no offerings and creates would break offline.
- **Agent fan-out protocol that worked**: explicit user authorization first; bead-per-agent
  created by the orchestrator (agents run NO bd commands — bd resolves from cwd and fails in
  ~/code/rockysurf); worktree-per-agent in the scratchpad; agents open PRs but never merge;
  orchestrator reviews diffs before merging; sequential merges with rebase for generator
  collisions (#111 needed one round; the conflict was additive, both test suites kept).

## Traps

  "reported" in plain text, went idle, and looked stalled. The fix: tell them in the brief to
  report via SendMessage to "main", and treat a bare idle ping with no prior report as "nudge
  for status", not as noise. (An idle ping AFTER a delivered report IS noise — both patterns
  occurred today.)
- **`gh pr checks --watch` exits 0 on failure** (carried; cost nothing today because everyone
  counted fail lines). Also: a rerun RESETS the check list — a watcher that attaches too soon
  sees "6 pass" and exits; sleep ~60s after `gh run rerun` before re-watching.
- **CI typechecks test files with `noUncheckedIndexedAccess`** — local vitest green is not
  CI green; `pnpm -r typecheck` before pushing (one PR bounced on `regions.eastus['x']`).
- **The AWS price feed is served gzipped with no content-encoding header** — naive fetch gets
  binary; sniff magic bytes (generator does).
- **Azure retail feed pages at ~1000 rows (7–9 pages/region), not 100** — the old comment was
  wrong by 10×; the guard now throws rather than truncating.
- **bd resolves its DB from cwd** — `bd` works from the archived-checkout cwd, fails from
  ~/code/rockysurf. Run bead commands from the session's default cwd.
