## Decisions and rules

- **A pass-along's `"305"` was a typo**; when an instruction names a merged PR, read the nearest
  open issues the conversation was about, do them all, and say so.
- **Personal provider install with a runtime dep**: extract the dependency's tarball beside the
  package under `<dataDir>/providers/node_modules/` — Node resolution finds it. The skill-built
  package depends on `@rockysurf/provider-sdk` (the skill never says whether a personal provider
  may have runtime deps: #410 gap 5).
- **The acceptance test must run outside the repo** with the skill copied out, the SDK tarballs
  from `pnpm pack`, and an explicit ban on reading the checkout — otherwise the in-tree provider
  contaminates it. Brief at scratchpad `do-retest/BRIEF.md`; it worked and is worth reusing.
- **Restarting the owner's server**: capture the running process's env via `ps eww` in memory and
  hand it to `start.sh` (`relaunch-server.py` in scratchpad); the shell profile does not carry the
  tokens. SIGTERM is ignored; escalate to SIGKILL after ~10 s. `SKIP_BUILD=1` after a build.
- **`rockysurf network sync` refuses when the config file differs from the running process** —
  by design; restart to adopt the file, then sync.
- **A probe droplet costs nothing measurable**: create the 512 MB size and delete it seconds later
  to test a request body against the real API when the dry run cannot (it refuses the create).

## Traps

- **`rockysurf token --help` MINTS A TOKEN** and prints it (the `token` command ignores `--help`).
  Never run it to read usage.
- **Fable agents end their turn to wait on their own CI watchers**, every time, even after being
  told not to. Watch PR checks centrally (`gh pr checks N --watch` in a background task) and treat
  the agent's "waiting" result as done-pending-CI.
- **`gh pr merge --delete-branch` prints an error when the branch is checked out in a worktree**
  but the merge itself succeeds; verify with `git log`, not the exit code.
- **The auto-mode classifier blocks MCP `create_server`** (billable) but not the CLI create nor
  MCP stop/start/terminate; `rm -rf` and chained `sleep` are blocked by dcg; use `mv` and
  background tasks.
- **pyenv's python3 on this machine lacks blake2** and spews hashlib errors; use `/usr/bin/python3`.
- **DO validation reports one error at a time**: a bad name and a bad key in the same body
  surface as whichever it checks first, so two bugs looked like one.
- **The old provider's error text pointed at the pack** for an apt lock; #404 reclassifies it.
