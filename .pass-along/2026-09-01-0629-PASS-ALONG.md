- **PR-only main, both repos** — the full recipe is a committed memory

  custody section is the contract; don't reintroduce a storage path.
- **Test matchers follow owner prose; never revert copy to fix a matcher.**
- **GitHub Actions cannot be a ruleset bypass actor** (not an installable app) — deploy keys
  are the supported bot-bypass; org setting `deploy_keys_enabled_for_repositories` gates them.

## Traps

- **`gh run rerun` reuses the original merge commit** — a rerun after a base-branch fix still
  tests the stale merge. Use `gh pr update-branch` to get a genuinely fresh run (bit both #271
  and #282).
- **`gh pr merge --auto` fails unless the repo's `allow_auto_merge` is on** — it was off here
  until 2026-08-31.
- **Month-rollover reds**: a test that pins dates but talks to a component reading the real
  clock passes until the calendar disagrees. The 00:00–01:00Z window theory was wrong; the
  divergence lasts as long as the months differ.
- **Shell cwd resets between Bash calls** — a relative-path script in a follow-up call can
  land edits in the wrong checkout. Check `git status` in both trees before assuming.
- **Foreground `sleep` is blocked; background tasks cap ~10 min** — long timers are chained
  background sleeps re-armed on each completion notification.
- **The first-run wizard lives at `/setup`** behind `SetupGate` (fires only when zero clouds
  are configured) — invisible on any configured install, which is how a credential-storing
  path survived unnoticed until this session.
- **better-sqlite3 v13 needs no install scripts** (bundled prebuilds) — do not resurrect
  #279's claim.
- Carried: node 24 via `~/.nvm/versions/node/v24.19.0/bin`; `/usr/bin/grep` for CI parity;
  never install/build/test in the owner's live checkout; dcg blocks `rm -rf` and scans heredoc
  content.
