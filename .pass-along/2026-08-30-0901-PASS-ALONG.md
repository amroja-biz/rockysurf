## Decisions and rules

- **A card that lights up under the pointer navigates.** Not a wrapping `<a>` (the card holds
  buttons and an inline `role=dialog`); an `onClick` that ignores controls, the dialog and text
  selections. The name keeps its own link for middle/cmd-click.
- **Core's `syncError` is rendered verbatim** — the provider wrote the remedy into it — and
  the web side only decorates it (`technicalProse()`); tests assert on `textContent`, which
  must not change.
- **Provider tabs: every configured cloud gets a tab even when empty** (a plain zero), and the
  URL carries the open tab under `?provider=`. Default = first cloud with a box.
- **A design-system audit is run against a throwaway instance on another port with its own
  dataDir**, never the owner's live app, and never their Chrome (a Claude-in-Chrome tab lands
  in their face; the predecessor learned that). Headless Playwright + `fake` provider is
  enough to render every screen with real data.
- **Reviewer agents are read-only and must cite `file:line`; the orchestrator re-verifies every
  citation.** One in twenty was wrong this time.
- **`bd init --stealth` still edits `.gitignore`** (adds a "Beads / Dolt files" block) — revert
  it; `.git/info/exclude` already carries `.beads/`.
