## Traps

- **`gh run list --commit <sha>` returned nothing** for a SHA that plainly had runs; match on
  `headSha | startswith(...)` from `--json` instead. A watcher keyed on `--commit` never fires.
- **The Bash tool's cwd drifts** between calls (a `cd` in one command persisted into the next;
  background commands don't propagate theirs). Two verification runs silently ran the wrong
  package's suite — same "29 files / 526 tests" twice was the tell. Use absolute paths.
- **The `dcg` guard blocks any command whose text contains `rm -rf /var/...`**, even inside a
  Docker `bash -c` string or a heredoc that only *writes* a script. Use the Edit/Write tools
  for file content, and `find … -delete` for in-container list wipes in ad-hoc repros.
- **`mergeStateStatus` sits at `UNKNOWN` for minutes** after checks pass on a busy day, not
  just ~10 s; the merge still works. `UNSTABLE` = checks pending, not failing.
- **agent-smoke run-N setup traps** (both now commented in the script): `--add-host` kills
  the mirror before the agent's own jq bootstrap runs → exit 2 before any step; and the
  `apt-updated` stamp survives in the shared state volume from run 5, so a later run's step
  skips `apt-get update`, fails on "Unable to locate package" with no fetch signature, and
  the fallback correctly never engages.
- **`apt-get update -qq` returns 0 on a dead mirror** — it prints `W: Failed to fetch` and
  `W: Some index files failed to download` and exits 0; only the following `install` fails.
  The fetch signature is in the W: lines, so a step that skips `update` has no signature.
- **`vi.spyOn(events, 'broadcastToUser').mock.calls[n][1]` is typed `object`**; cast it.
- **Apostrophes in single-quoted test strings** ("Ubuntu's") — two syntax errors from one
  copy-paste. Use double quotes for prose.
- **The default AWS profile is a `cloudwatch-ro` user in another account**; the `rockysurf`
  profile is SSO and was expired. The CI account is `089781651193`.
- Carried, still true: node 24 (`nvm use 24`); no eslint/prettier in the repo — CI's "Lint"
  is `pnpm lint` structure scripts; `gh pr checks --watch` exits 0 on failure.
