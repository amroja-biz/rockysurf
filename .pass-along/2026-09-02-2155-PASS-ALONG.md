## Decisions and rules

- **SSH "filtered" ≠ box/cloud bug.** On some networks SSH (port 22) egresses from a different
  public IP than web (443/checkip/ifconfig.me). Diagnose an allow-list "filtered" by checking the
  client's actual port-22 egress IP (e.g. `curl http://portquiz.net:22/`) before suspecting the
  box or cloud. #324 bakes this into the product guidance.
- **Backup/Restore (ADR-0023)**: master key NEVER in the artifact (operator carries `secret.key`
  by hand); encrypted secrets travel as verbatim ciphertext; literal GitHub PATs ALWAYS redacted
  to `${VAR}` (owner ruling — restore lists them by name to re-enter); identity reconciled by
  githubId with github-token re-seal under the new machine's userId; records-not-machines (cloud
  boxes are not restorable); the JSON backup COEXISTS with the manual `tar` (doesn't replace it).
- **Two different SG revokes, two different homes.** The published `iam-role.yaml` legitimately
  gains `RevokeSecurityGroupIngress` (scoped `RevokeSshOnOwnGroupOnly`) for the #309 *product*
  feature. CI's revoke stays OUT of the published role — it runs on the operator/entry-role seam
  (#325/#327). Don't conflate them.
- **ADR & migration numbers collide across parallel agents.** #299 and #331 both grabbed ADR-0022;
  #331 renumbered to 0023. #299 took migration 0019. Verify the free number at branch/rebase time,
  not from a plan doc.
- **socket-activated sshd**: `ssh.service` inactive + `/run/sshd` absent + `sshd -t` failing is
  the NORMAL resting state before the first connection — not a fault (the #321 lesson).
