## Decisions and rules

- **"We list what we can price."** The #24 design consensus (Fable + Opus phone-a-friend,
  3 rounds — full doc at the session scratchpad's plan-issue-24.md, but the durable record
  is PR #71/#69/#73's bodies): catalogue breadth is bounded by priced rows because unpriced
  rows are invisible to the spend cap. Live cloud-API catalogues were REJECTED for this
  reason (plus IAM churn and the fully-specified-create-survives-outage property). AWS/Azure
  breadth comes from the pricing-feed generators; GCP stays curated (no credential-free feed).
- **`custom` size, not nullable size.** servers.size is a text() column; widening the TS
  type needed NO migration. A nullable column would have been the repo's first destructive
  SQLite table-recreate, with a cascade FK pointed at the billing table. Do not revisit
  without a seeded-migration test.
- **The ceiling constant**: picker catalogues cap at 128 vCPU / 1024 GiB (AWS generator-time,
  Azure runtime gate — same policy, cross-referenced comments). Owner may tighten to 64/512
  by changing one constant per side.
- **Comment policy direction** (#75): comments state constraints code can't show; history
  goes to git log/ADRs/docs; bead ids live in commit subjects. Not yet enforced — #76 does
  the sweep AFTER #75's docs exist.
- **CORE-PRINCIPLES.md governs features**; issues/PRs name the principle served; principle
  conflicts get ADRs. BYOC/BYOK/BYOR is a design boundary, not marketing: features making
  Rocky Surf a party to the user's cloud/key/repo relationships are out of bounds.
- **CI's pack-smoke matrix is the authoritative smoke** when local Docker would load the
  host; agents state plainly in PR bodies which legs ran where.
- **Sold-out picker rows show generic wording** — verified across all four providers that
  `Offering` carries no per-row reason on the wire; GCP's zone message only exists in
  validateSpec. A per-row reason field would be an SDK change (ADR territory).

## Traps

- **Subagents in this setup routinely go idle WITHOUT delivering their final report.** A
  SendMessage nudge always shook the report loose (5+ times today). Don't respawn; nudge.
- **`scripts/sync-packs-bundle.mjs` resolves from cwd and expects to run from
  `packages/core`** (`node ../../scripts/sync-packs-bundle.mjs`). From a worktree root it
  fails with a misleading "no packs to copy" naming a path two levels up.
- **QEMU-emulated amd64 on Apple Silicon crashes bun** (spurious MemoryExhaustion at ~30MB
  RSS, upstream oven-sh/bun issue) — an OMP/bun smoke failure under local emulation is the
  emulator, not the pack. CI's native runners are the truth.
- **Never run `gitleaks git .` in a checkout sharing this session-repo's object store** —
  ~80 branches from other sessions plus the archived private repo's history produce
  thousands of false findings. farm-gitleaks verified against a fresh isolated clone; do the
  same. (A leftover such clone, `rockysurf-check/`, sits untracked in the old checkout.)
- **The dcg command guard blocks `rm -rf` and `git reset --hard`** even in scratch dirs —
  use unique target dirs instead of rm, and `git merge --ff-only` instead of reset.
- Carried: node 24 for pnpm; fresh worktrees need `pnpm install` AND `pnpm -r build`;
  bd resolves its DB to the old private checkout — run bd from the main checkout, never
  `bd -C` into a worktree; `echo ===` breaks zsh; shell cwd resets between Bash calls.
