## Traps

- **npm 11.17's 2FA and propagation behaviour** (cost five bootstrap runs tonight; all now in
  `scripts/npm-bootstrap-trust.mjs` comments): npm shows its browser OTP prompt ONLY when its
  stdout is the terminal, so any npm write whose output you capture fails with EOTP; `npm trust
  list` is itself behind 2FA and with `--json` prints its error on stdout; the read path lags a
  first publish by ~4 minutes (deprecate/trust/`npx` all 404 meanwhile) while `npm access get
  status` sees it at once; one trusted publisher prints as a bare object. The release smoke step
  hit the same lag (#460).

  declarations; ci.yml always built first. Fixed in #458. A tag that fails before Publish can be
